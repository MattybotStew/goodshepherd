## URL rules

These prototype-era URLs are wrong and must not be published:

| Wrong | Right |
|---|---|
| `/programs#health` | `/programs/health-well-being/` |
| `/programs#community-day` | `/programs/community-day-services/` |
| `/programs#vocational` | `/programs/community-day-services/#vocational-classroom` |
| `/programs#residential` | `/programs/residential-living/` |
| `/support-gsm#events` | `/events/` |
| `/ways-to-give/` | `/support-gsm/#ways-to-give` (301) |
| `/donate/` | `/support-gsm/` (301) |

## Not navigable by design

`/newsletters/` is deliberately absent from the header nav and footer quick links (client call, 2026-11-05). It is reached from page content only.
